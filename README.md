# 📝 Introduction

**Octo** is a sophisticated desktop board game built from scratch using **C# and .NET WinForms**. 
The game challenges players to navigate 8 pieces across the board based on dice rolls, requiring both luck and strategy to finish before the opponent.

The project showcases advanced **Object-Oriented Programming (OOP)**, custom **AI behavior**, and a highly polished **Dark Mode UI**.

---

# 📖 How to Play

| 📜 Rules & Strategy | 🖼️ Visual Guide |
| :--- | :--- |
| 1. **Objective**: Be the first player to move all **8 pieces** from the starting area to the finish line.<br><br>2. **Movement**: Roll the dice each turn to determine how many steps your piece can take.<br><br>3. **Collision Rules**: You cannot land on a square already occupied by an opponent's piece. Plan your moves to block their path!<br><br>4. **Turn Logic**: If no valid moves are available for your current roll, your turn is automatically skipped.<br><br>5. **Winning**: The game ends instantly when one player successfully moves all pieces to the end zone. | <img src="https://github.com/MrwnMoh/Octo/blob/main/Pics/How%20To%20play%20Vis.png" width="500"/> |

# 🚀 Main Features

## 🎮 1. Dynamic Gameplay
* **Dice-Based Movement:** Integrated random dice engine to determine steps.
* **Piece Management:** Control 8 individual pieces (Black & White) with unique state tracking.
* **Collision Detection:** Advanced logic prevents moving into occupied opponent spaces.

---

## 🧠 2. Smart AI & Logic
* **Decision Engine:** The AI evaluates valid moves and prioritizes the best path.
* **Turn Validation:** Automatic skip logic if no valid moves are available for the current roll.
* **AI vs AI Mode:** A dedicated mode to watch the computer's logic in action.

---

## 🎨 3. Premium UI/UX
* **Interactive Animations:** Smooth hover effects and step highlighting for better UX.
* **Game Timer:** High-precision timer tracking (Hours : Minutes : Seconds).
* **Sound Integration:** Immersive audio feedback for moves and UI interactions using `SoundPlayer`.
